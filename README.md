# Merach P16 IMC Tracker

MERACH P16 All-in-One Home Gym Dual-Angle Smith 上市信息释放周报，按周追踪 EDM、官网、Google 搜索广告、Reddit、Instagram、Facebook、Threads、X、YouTube、TikTok、Amazon / 零售 / KOL / PR 等渠道的内容与数据。

- `index.html`：周报页面（单文件，直接用浏览器打开；开启 GitHub Pages 后可在线查看）
- `data.json`：周报数据（各期要点、内容条目、渠道数据、质量评级、汇总）
- `build.py`：修改 `data.json` 后运行，将数据写入 `index.html`
- `MAINTENANCE.md`：更新规则与各渠道取数方式

在线版本（Claude Artifact）：https://claude.ai/artifact/6kUB9vGV1NA8cW5zDgbU2H

更新节奏：每周一（上海时间）更新一期；期间手动刷新时延长当期区间，不新增一期。
